# 📦 BODEGA Pro — Sistema de Diseño y Design Tokens

Este repositorio contiene la arquitectura del **Sistema de Diseño y Abstracción Semántica** para la plataforma **BODEGA Pro**. Se han extraído y desacoplado todas las variables visuales (colores, tipografía, espaciado, elevaciones y animaciones) de la interfaz del catálogo público (`index.html`) y del panel de administración (`admin.html`) hacia una estructura modular basada en **Design Tokens Semánticos**.
